## A 端到端流程需求（按图分层）

### A1 Strategic Layer
意图/目标/长期规划

#### 功能需求
M1
- 识别用户意图并形成可验证的目标与成功标准
- 约束识别包含预算、合规、风险等级与时间范围
- 形成任务总体方向与优先级，并输出阶段性里程碑
- 将目标与租户策略绑定并形成可审计的决策摘要
M2
- 支持多目标权衡与长期目标分段规划
- 支持跨会话的战略意图继承与修订
M3
- 支持跨组织目标协同与冲突消解

#### 输入/输出语义
M1
- 输入标识字段
```
tenant_id
task_id
session_id
trace_id
```
- 输入包含用户意图、约束条件、风险等级、预算上限与时限
- 输出包含战略目标、成功标准、优先级、预算分配与阶段性里程碑
- 输出包含战略层状态标识
```
待处理
进行中
阻塞
完成
失败
人工介入中
```
M2
- 输入支持多目标权重与长期目标版本号
- 输出包含目标权衡依据与修订原因
M3
- 输入包含跨组织授权上下文
- 输出包含跨组织协同的决策摘要与责任边界

#### 事件类型
M1
```
WORKFLOW_STARTED
DATA_PROCESSING
AGENT_THINKING
PROGRESS
ERROR_OCCURRED
```
说明
- 1 工作流启动事件。
- 2 上下文与目标整理事件。
- 3 战略推理事件。
- 4 里程碑生成与更新事件。
- 5 战略层失败事件。
M2
```
APPROVAL_REQUESTED
APPROVAL_DECISION
WAITING
```
说明
- 1 高风险战略决策的人工审批请求。
- 2 审批结果回传。
- 3 等待审批或外部输入。
M3
```
TEAM_STATUS
```
说明
- 1 跨组织协同状态更新事件。

#### 失败与恢复语义
M1
- 失败类型包含意图冲突、目标不可行、策略不满足与预算不足
- 失败必须输出可追溯原因与决策证据
- 失败后允许触发人工介入并进入阻塞状态
- 恢复后必须复用原始输入与已确认目标
M2
- 失败可触发替代目标方案并记录决策分歧
- 恢复可基于修订后的约束重新计算里程碑
M3
- 跨组织冲突必须进入人工介入并完成授权确认

#### 验收标准
M1
- 输入缺失标识字段的请求被拒绝率达到 100%
- 战略目标输出包含成功标准的比例达到 100%
- 风险等级为高的任务触发人工介入比例达到 100%
M2
- 多目标权衡记录可查询比例达到 100%
M3
- 跨组织授权缺失的任务被阻断比例达到 100%

#### 与其他层交互
- 向战术层输出目标、约束与里程碑作为拆解输入
- 从记忆层读取用户偏好与历史目标并更新记忆摘要
- 向反馈层提供成功标准用于结果评估与回溯

## C 需求一致性与范围约束

### M1 最小闭环端到端验收
- 用户提交任务后生成唯一标识并可查询
- 战略、战术、推理、行动计划、执行、反馈、记忆各层均产出事件且可在时间线中查询
- 端到端链路至少产生以下关键事件
```
WORKFLOW_STARTED
WORKFLOW_COMPLETED
```
- 实时流通道可订阅并按序接收事件
- 任务完成后可查询时间线与审计记录
- 结果评估可回溯到成功标准并生成反馈
- 关键结果写入记忆层并可被后续任务检索
- 断线重连后事件流可从游标位置继续

### 明确不做
- 不提供模型训练与微调能力
- 不建设面向终端用户的通用应用界面
- 不承诺覆盖所有外部系统与工具生态
- 不提供跨组织数据共享与联邦协作
