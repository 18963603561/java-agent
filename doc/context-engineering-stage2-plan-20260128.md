# 上下文工程阶段二任务拆分与验收排期

## 输入依据
```
doc/context-event-payload-stage2-scope-20260128.md
```

## 目标
- 落地记忆过期、记忆脱敏与结构化摘要三项能力。
- 保持多租户隔离与主流程稳定，新增能力以扩展方式引入。
- 补齐日志、可观测性与可验证的验收用例。

## 任务拆分

### 一、记忆过期
#### T2-1 数据结构与配置
- 范围：`MemoryRecord` 新增过期字段；`MemoryPolicyProperties`、`MemoryWriteProperties` 增加过期策略配置。
- 产出：字段与配置项、默认值、配置说明。

#### T2-2 写入链路过期计算
- 范围：`MemoryWriteService` 写入时计算过期时间并落库。
- 产出：写入日志包含过期策略摘要。

#### T2-3 召回链路过期过滤
- 范围：`MemoryRecallService` 召回结果过滤过期记录；`MemoryStore`、`MemoryRepository` 支持过期过滤。
- 产出：过期记录不进入上下文快照。

#### T2-4 清理任务与触发策略
- 范围：新增定时清理或按查询清理策略。
- 产出：清理统计日志与指标。

#### T2-5 测试与验收
- 范围：新增/更新单元测试与集成测试。
- 产出：覆盖过期计算、过滤、清理与边界条件。

### 二、记忆脱敏
#### T2-6 脱敏规则与执行器
- 范围：新增脱敏执行器与规则配置，支持可扩展。
- 产出：规则集、开关、忽略名单。

#### T2-7 写入链路脱敏
- 范围：`MemoryWriteService` 写入前脱敏。
- 产出：脱敏前后差异统计与审计标记。

#### T2-8 召回链路脱敏
- 范围：`MemoryRecallService` 召回后脱敏。
- 产出：脱敏标记进入上下文快照摘要。

#### T2-9 ContextBuilder 标记与审计
- 范围：在 `ContextSnapshot` 或相关摘要中记录脱敏信息。
- 产出：事件载荷中可追踪的脱敏统计字段。

#### T2-10 测试与验收
- 范围：新增/更新单元测试与集成测试。
- 产出：覆盖规则匹配、开关、忽略名单与边界条件。

### 三、结构化摘要
#### T2-11 摘要结构定义
- 范围：新增结构化摘要对象，如 `ConversationSummary`、`WorkingMemorySummary`。
- 产出：结构字段与版本标识。

#### T2-12 压缩链路输出结构化摘要
- 范围：`CompressionRequest`、`MemoryStore#compress` 输出结构化摘要。
- 产出：摘要产物与版本记录。

#### T2-13 ContextBuilder 消费结构化摘要
- 范围：`ContextBuilder` 消费结构化摘要并填充 `WorkingMemory`、`EvidencePack`。
- 产出：上下文快照与提示词可使用结构化摘要。

#### T2-14 事件载荷摘要统计补充
- 范围：事件载荷输出摘要统计信息。
- 产出：事件中包含摘要条目与长度统计。

#### T2-15 测试与验收
- 范围：新增/更新单元测试与集成测试。
- 产出：覆盖摘要生成、版本化与裁剪触发逻辑。

## 验收清单
- 记忆过期：写入时生成过期时间；召回结果无过期记录；清理机制可追踪。
- 记忆脱敏：写入与召回均完成脱敏；脱敏统计可在事件中审计。
- 结构化摘要：压缩输出结构化产物；上下文快照可使用结构化摘要；事件可追踪摘要统计。
- 可观测性：关键路径与异常处均有日志，指标与事件可回溯。

## 排期建议

### 第一周
- T2-1、T2-2、T2-3：完成过期字段、配置与写入/召回过滤。
- T2-4：清理策略雏形与日志指标。

### 第二周
- T2-5：过期链路测试与验收用例补齐。
- T2-6、T2-7：脱敏执行器与写入链路接入。

### 第三周
- T2-8、T2-9：召回脱敏与上下文标记。
- T2-10：脱敏测试与验收用例补齐。

### 第四周
- T2-11、T2-12：结构化摘要数据结构与压缩输出。
- T2-13、T2-14：上下文消费与事件统计补充。
- T2-15：结构化摘要测试与验收用例补齐。

## 风险与依赖
- 过期与脱敏策略需要跨存储与召回链路一致实现。
- 结构化摘要需要与现有压缩策略兼容，避免引入回归。
- 事件载荷字段扩展需保持向后兼容。
