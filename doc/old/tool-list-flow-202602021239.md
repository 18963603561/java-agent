# 外部工具清单获取与加载流程分析

## 1. 结论摘要
- 启动阶段仅加载本地默认工具与插件目录工具，不会主动拉取远程 MCP 工具清单。
- 远程工具清单的拉取由按需触发驱动，核心入口是工具目录查询与模型工具注入流程。
- 外部接口 `/api/v1/mcp/tools/list` 会直接请求 MCP 服务返回清单，但不会写入本地注册表。

## 2. 关键组件与职责
### 2.1 工具注册表
- 组件：`ToolRegistry`
- 职责：保存工具定义与执行处理器，提供查询与执行。
- 位置：`src/main/java/com/example/agent/agentcore/ToolRegistry.java`

### 2.2 插件工具加载
- 组件：`PluginLoader`
- 职责：启动时扫描插件目录并注册工具定义。
- 触发：`@PostConstruct` 自动调用。
- 位置：`src/main/java/com/example/agent/tools/plugin/PluginLoader.java`

### 2.3 工具目录与刷新入口
- 组件：`DefaultToolCatalog`
- 职责：提供工具摘要、工具定义、工具输入结构查询。
- 特点：每次查询前会调用远程刷新入口。
- 位置：`src/main/java/com/example/agent/tools/DefaultToolCatalog.java`

### 2.4 MCP 工具同步
- 组件：`McpToolSyncService`
- 职责：从远程 MCP 拉取工具列表并写入本地注册表。
- 触发：由工具目录查询时触发，不在启动时自动执行。
- 位置：`src/main/java/com/example/agent/tools/McpToolSyncService.java`

### 2.5 MCP 工具客户端
- 组件：`McpToolClient`
- 职责：对外提供 MCP 列表与调用的统一入口，支持本地与远程策略。
- 位置：`src/main/java/com/example/agent/tools/McpToolClient.java`

### 2.6 模型工具注入
- 组件：`ModelToolResolver`
- 职责：将工具定义或摘要注入模型请求。
- 位置：`src/main/java/com/example/agent/model/ModelToolResolver.java`

### 2.7 上下文构建中的工具摘要
- 组件：`DefaultContextBuilder`
- 职责：构建工具状态时拉取工具摘要。
- 位置：`src/main/java/com/example/agent/context/DefaultContextBuilder.java`

## 3. 启动阶段是否加载所有工具
- 启动会加载：
  - `ToolRegistry` 构造函数注册默认工具。
  - `PluginLoader` 在 `@PostConstruct` 中加载插件目录工具。
- 启动不会加载：
  - 远程 MCP 工具清单不会在启动时主动拉取。
  - 远程同步仅在调用工具目录查询时触发。

## 4. 拉取外部工具清单的场景
### 4.1 模型工具注入触发
- 入口：`ModelToolResolver.applyTooling(...)`
- 当注入模式为摘要时会调用 `ToolCatalog.listSummaries(...)`。
- `DefaultToolCatalog` 在 `listSummaries(...)` 内部调用 `refreshRemoteTools(...)`。
- `McpToolSyncService.refreshIfNeeded(...)` 会拉取远程工具清单并写入注册表。

### 4.2 上下文构建触发
- 入口：`DefaultContextBuilder.buildToolState(...)`
- 该方法调用 `ToolCatalog.listSummaries(...)`，触发与 4.1 相同的远程同步。

### 4.3 获取工具定义或输入结构时触发
- 入口：`DefaultToolCatalog.getDefinition(...)` 与 `DefaultToolCatalog.getToolSchema(...)`
- 在读取本地定义前同样触发 `refreshRemoteTools(...)`。

### 4.4 外部 API 直接拉取
- 入口：`/api/v1/mcp/tools/list`
- 控制器：`McpController.listTools(...)`
- 调用：`McpToolClient.listTools(...)` 根据策略调用远程或本地。
- 注意：此路径返回结果给调用方，但不会写入本地注册表。

## 5. 远程清单拉取与写入流程
### 5.1 远程拉取
- `McpToolSyncService.refreshServer(...)` 调用 `McpToolClient.listToolsRemoteOnly(...)`。
- 使用空的 `McpToolListRequest`，由远端返回工具列表。
- 配置项 `agent.mcp.tool-refresh.max-tools` 用于限制最大工具数量。

### 5.2 注册表写入
- `applyToRegistry(...)` 以 `mcp:<serverId>` 作为来源写入。
- 同一来源工具允许覆盖更新。
- 会删除该来源下已下线的旧工具定义。

### 5.3 缓存与刷新策略
- 缓存键：`mcp:tools:<serverId>`。
- 由 `agent.mcp.tool-refresh.ttl-seconds` 控制刷新频率。
- `agent.mcp.tool-refresh.enabled` 关闭时不会拉取远程清单。

## 6. “全部工具清单”触发条件说明
- 只要调用工具目录查询并触发同步，就会请求远端 MCP 的工具列表。
- 当前同步实现只执行一次远程列表请求，不进行分页循环。
- 远端分页由 `McpToolListResponse` 的 `nextCursor` 表示，但同步流程未继续拉取后续页。

## 7. 本地与远程合并策略
- `McpToolClient.listTools(...)` 受以下配置影响：
  - `agent.mcp.call-strategy`：`remote-first`、`local-first`、`local-only`、`remote-only`。
  - `agent.mcp.merge-local-tools`：允许合并本地注册表工具。
  - `agent.mcp.fallback-to-local`：远端失败时回退本地。
- 该策略仅影响外部 API 查询路径，不影响同步写入路径。

## 8. 典型流程简述
### 8.1 模型注入路径
1) `ModelToolResolver.applyTooling(...)`
2) `DefaultToolCatalog.listSummaries(...)`
3) `McpToolSyncService.refreshIfNeeded(...)`
4) `McpToolClient.listToolsRemoteOnly(...)`
5) 写入 `ToolRegistry`
6) 返回工具摘要给模型

### 8.2 外部接口查询路径
1) `McpController.listTools(...)`
2) `McpToolClient.listTools(...)`
3) 根据策略走远端、本地或合并
4) 返回结果给调用方
