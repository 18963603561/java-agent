# P2改造落地与测试报告-20260211

## 1. 目标与范围

- 目标：按照 `doc/20260211/P2改造任务清单-Actor审计回放诊断-202602111631.md` 完成 P2 全量落地。
- 范围：
  - P2-1：DAG 审计底座（运行主记录、节点尝试、依赖投递、背压记录）
  - P2-2：DAG 语义回放（服务 + 接口 + 过滤分页）
  - P2-3：DAG 诊断闭环（原因码、诊断服务、接口）
- 约束：新方案直接落地，不保留历史兼容分支；每阶段执行完整测试验证。

## 2. 本次落地改造清单

### 2.1 P2-1 审计底座

- 审计仓储扩展：
  - `DagAuditRepository` 新增 `findRunRecordsByWorkflow(workflowId)`。
  - `InMemoryDagAuditRepository` 实现按工作流查询运行记录。
  - `DagAuditService` 新增按工作流查询能力。
- 运行时接入与收敛：
  - `DagActorRuntime` 增加测试构造器：`(WorkspaceSyncService, MultiAgentEventPublisher, DagSupervisorPolicy, DagBackpressurePolicy)`，恢复既有测试调用方式。
  - 移除重复失败审计写入路径：删除 `saveNodeAttemptFailureRecord(...)` 的双写逻辑，避免失败尝试记录重复。
  - 保持 `dagRunId` 在运行结果与协调器输出中可用。

### 2.2 P2-2 回放能力

- 事件锚点补齐：
  - `MultiAgentEventPublisher` DAG 相关事件新增重载版本，支持附带：`dagRunId/nodeId/attempt/reasonCode/messageId`。
  - `DagActorRuntime` 全路径调用升级为带锚点版本，覆盖：节点开始、完成、失败、等待、背压、重试。
- 回放服务新增：
  - 新增 `DagReplayService`，聚合 `DagAuditService + EventLogRepository`，支持参数：
    - `workflowId`
    - `dagRunId`
    - `cursor`
    - `size`
    - `fromSeq`
    - `toSeq`
    - `nodeId`
    - `attempt`
  - 支持游标分页、运行过滤、节点过滤、尝试过滤、序号区间过滤。
- 回放接口新增：
  - 新增 `GET /api/v1/workflows/dag/replay`。
  - 完整接入鉴权、租户上下文与统一响应结构。

### 2.3 P2-3 诊断闭环

- 原因码体系：
  - 新增 `DagFailureReasonCode`。
  - 新增 `DagBlockingReasonCode`。
- 诊断模型与服务：
  - 新增 `DagDiagnosisReport`。
  - 新增 `DagDiagnosisService`，输出：
    - 关键路径热点节点
    - 最长等待节点
    - 重试热点节点
    - 背压热点节点
    - 失败原因分布
    - 阻塞原因分布
    - 建议动作列表
- 诊断接口新增：
  - 新增 `GET /api/v1/workflows/dag/diagnosis`。
  - 接入鉴权、租户上下文与统一响应结构。
