# P2改造落地与测试报告（包设计合理性）

## 1. 改造目标

本次按照 `doc/20260211/P2改造任务清单-包设计合理性-202602112113.md` 分阶段完成落地，重点覆盖：

1. 统一状态与原因码，消除字符串散落。
2. 统一步骤参数读取，减少重复解析逻辑。
3. 收敛装配边界，避免默认误装配 InMemory 实现。
4. 按阶段执行专项测试并完成全量回归。

## 2. 阶段A（DTO化）

阶段A在本轮前已完成并作为基线沿用，当前代码已保留：

1. `Map<String,Object>` 主流程改为显式 DTO 传递。
2. `MultiAgentCoordinator` 保留边界层 `Map` 输出转换。
3. `SupervisorCoordinatorTest` 已对 DTO 契约做断言。

本轮补充执行了阶段A专项回归，结果通过（见“测试执行记录”）。

## 3. 阶段B（状态与原因码枚举化）

### 3.1 已完成改造

1. 新增并统一使用枚举：
   - `RunStatus`
   - `ReasonCode`
   - `ControlCommandType`
2. `DagNodeExecutionService`：
   - 失败路径由字符串原因码切换为 `ReasonCode`。
   - 团队状态发布 `DAG_NODE_FAILED` 切换为 `RunStatus` 输出。
3. `DagActorRuntime`：
   - 空 DAG 结果状态改为 `RunStatus.COMPLETED`。
   - ready-queue 节流原因码改为 `ReasonCode.READY_QUEUE_THROTTLED`。
   - 异常状态发布改为 `RunStatus.FAILED`。
4. `SupervisorCoordinator`：
   - 状态流转使用 `RunStatus`。
   - handoff 失败原因码统一使用 `ReasonCode`。
5. `DagControlService`：
   - 全量重写为枚举驱动命令分发。
   - 控制结果状态统一由 `RunStatus` 导出。
   - 事件发布状态统一为 `RunStatus.DAG_CONTROL`。

### 3.2 质量修正

1. 新增枚举文件中的中文注释乱码已修正。
2. 控制面状态判定改为枚举比较，避免字符串硬编码。

## 4. 阶段C（参数读取器收敛）

### 4.1 新增能力

新增 `StepArgumentReader`，统一提供：

1. `readString`
2. `readStringList`
3. `readMap`
4. `normalizeStringList`

统一处理空值、trim、去重、非预期结构降级。

### 4.2 替换落点

1. `ExecutionRouteDecider.resolveTopicList` 复用 `StepArgumentReader`。
2. `DagPlanner.resolveStringList` 改为复用读取器。
3. `DagPlanner.resolveRoleDependencies` 改为基于读取器归一化映射。

### 4.3 测试配套调整

为保持构造注入一致性，更新测试中的手动构建：

1. `DagPlannerTest`
2. `MultiAgentCoordinatorTest`
3. `MultiAgentCoordinatorDagActorTest`

## 5. 阶段D（装配边界治理）

### 5.1 默认误装配治理

移除以下 InMemory 组件 `matchIfMissing=true`，改为显式 `mode=inmemory` 才装配：

1. `InMemoryHandoffRepository`
2. `InMemoryDagAuditRepository`
3. `InMemoryDagRuntimeStateRepository`
4. `InMemoryDagMessageDedupRepository`
5. `InMemoryDagDeadLetterRepository`
6. `InProcessDagMailboxTransport`（transport 需显式为 inprocess）

### 5.2 启动校验增强

新增 `MultiAgentTransportConfiguration`：

1. 强制要求配置 `agent.dag.distributed.transport`。
2. 当 transport 非 `inprocess` 时，禁止装配 `InProcess` 传输实现。
3. 启动时输出明确校验日志。
