本次落地基于 `doc/20260211/P2改造任务清单-对齐Shannon-202602111252.md`，覆盖以下范围：

## 2. 代码落地清单

### 2.1 P2-1 交接状态一致性

1) 新增交接状态模型与状态机：

- `HandoffStatus`
- `HandoffStateMachine`

2) 新增交接仓储与版本冲突控制：

- `HandoffRepository`
- `InMemoryHandoffRepository`

3) 扩展交接实体字段：

- `HandoffRecord`：`version`、`updatedAt`、`idempotencyKey`、`errorCode`
- `HandoffResult`：`status` 改为枚举并增加 `version`
- `HandoffRequest`：增加 `idempotencyKey`

4) 重构交接服务：

- `HandoffService` 全状态变更经 `HandoffStateMachine`
- 使用 `compareAndSet` 做乐观并发更新
- 幂等键命中返回同一交接记录结果

5) Supervisor 生命周期接入：

- `SupervisorCoordinator` 增加 `WAITING/RUNNING/FAILED/SUCCEEDED` 推进
- 增加终态守卫，避免 `FAILED -> SUCCEEDED` 非法迁移

### 2.2 P2-2 背压事件矩阵

1) 治理拒绝结构化异常：

- 新增 `GovernanceRejectionException`

2) 限流与熔断结构化决策：

- `RateLimitDecision`
- `CircuitDecision`
- `RateLimitService` 与 `CircuitBreakerManager` 新增 `evaluate(...)`

3) `McpToolClient` 治理上下文透传：

- `RATE_LIMITED`、`CIRCUIT_OPEN` 抛出结构化异常上下文

4) 网关治理事件发布：

- `EnforcementGateway` 捕获 `GovernanceRejectionException`
- `RATE_LIMITED` -> `BACKPRESSURE_APPLIED`
- `CIRCUIT_OPEN` -> `CIRCUIT_OPENED` + `BACKPRESSURE_APPLIED`
- 保持 `TOOL_ERROR` 不回归

5) 重试等待可观测：

- `ToolExecutor` 增加带 `workflowId/seqCounter` 的执行接口
- 可重试退避前发布 `WAITING`
- 限流/熔断退避补发 `BACKPRESSURE_APPLIED`
- 去除从 `TaskRequest.context` 反序列化 `AtomicLong` 的不合理实现

6) 预算背压增强：

- `BudgetEventPublisher` 增加 `publishBackpressureEvent(...)`
- `DefaultBudgetEventPublisher` 发布预算 `BACKPRESSURE_APPLIED`
- `TokenBudgetManager` 在阈值命中时同时发布 `BACKPRESSURE_APPLIED` 与 `BUDGET_THRESHOLD`

## 5. 剩余风险与后续建议

1) `HandoffRepository` 当前为内存实现，建议下一阶段替换为持久化实现并补齐迁移脚本。  
2) `Supervisor` 生命周期当前复用 `handoff` 领域对象，可在后续版本拆分专用生命周期模型。  
3) 治理事件建议接入统一事件契约校验器，进一步约束 payload 字段一致性。
