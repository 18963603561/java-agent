- 新增共享内核包：`com.example.agent.budget.core`。

  - `ContextBudgetAllocation`
  - `ContextBudgetPolicy`
  - `ContextBudgetProperties`
  - `ContextSection`
  - `ContextTrimSection`
- 全项目引用统一切换到 `budget.core`。

### 2.2 核心结果

- `src/main/java/com/example/agent/budget/token` 不再 import `com.example.agent.budget.trim.*`。
- `src/main/java/com/example/agent/budget/trim` 不再 import `com.example.agent.budget.token` 的核心模型。

- 新增裁剪上下文对象：`TrimContext`。

- 新增裁剪处理器基类：`AbstractContextTrimHandler`。
