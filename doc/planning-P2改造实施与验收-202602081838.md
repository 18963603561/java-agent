# planning 包 P2 改造实施与验收

## 1. 目标与范围

- 依据文档：`doc/planning包设计合理性评审-202602081543.md`
- 执行清单：`doc/planning-P2改造任务清单-202602081806.md`
- 本次执行范围：
  1. 清理与契约收口（遗留模型出口、常量统一）
  2. 编码与换行守卫增强（planning 源码 + 提示词模板）
  3. 策略分支改造为“注册机制 + 处理器”
  4. 组件与集成测试收口，并完成阶段性全量回归

## 2. 分阶段实施结果

## 2.1 阶段一：清理与守卫

### 已完成

1. 复核并保持遗留模型清理结果：
   - `Plan`、`PlanRequest` 保持删除状态，仓内无残留引用。
2. 扩展编码守卫测试：
   - `PlanningSourceEncodingGuardTest` 扫描范围从 `planning/*.java` 扩展到 `planning/*.java + prompts/planning/*.md`。
   - 增加替换字符 `\uFFFD` 检测，阻断乱码回归。
3. 新增 LF 行结束符守卫：
   - `PlanningLineEndingGuardTest` 校验 planning 主代码、测试代码、提示词模板均为 LF。
4. 修复格式违规文件：
   - `PlannerProperties.java`、`PlanResult.java` 重建为 UTF-8（无 BOM）+ LF。

### 阶段一测试

- `mvn -q -Dtest=PlanningSourceEncodingGuardTest test`：通过
- `mvn -q -Dtest=PlannerServiceTest test`：通过
- `mvn -q test`：通过

## 2.2 阶段二：策略注册化改造

### 已完成

1. 新增策略抽象层：
   - `planning/strategy/PlanningStrategyType`
   - `planning/strategy/PlanningStrategyHandler`
   - `planning/strategy/PlanningStrategyContext`
   - `planning/strategy/PlanningStrategyResult`
   - `planning/strategy/PlanningStrategyRegistry`
   - `planning/strategy/AbstractPlanningStrategyHandler`
2. 新增策略处理器：
   - `ChainOfThoughtStrategyHandler`
   - `ThoughtTreeStrategyHandler`
   - `MultiAgentStrategyHandler`
   - `DebateStrategyHandler`
   - `ResearchStrategyHandler`
   - `ReactStrategyHandler`
   - `DirectLlmStrategyHandler`
   - `ToolFallbackStrategyHandler`
3. `HeuristicPlanBuilder` 重构为策略调度器：
   - 保留复杂度估算与策略默认值计算。
   - 通过 `PlanningStrategyRegistry` 执行策略链路，不再堆叠分支实现。
4. 增强可观测性：
   - 策略调度开始/结束日志。
   - 策略处理器异常统一记录堆栈并上抛。
5. 契约常量补齐：
   - `PlanningContextKeys` 新增策略相关常量（multi_agent/debate/research/react/cot/tree_of_thoughts 等）。

### 阶段二测试

- `mvn -q -Dtest=HeuristicPlanBuilderTest test`：通过
- `mvn -q -Dtest=PlanningStrategyRegistryTest test`：通过
- `mvn -q -Dtest=PlannerServiceTest test`：通过
- `mvn -q test`：通过
