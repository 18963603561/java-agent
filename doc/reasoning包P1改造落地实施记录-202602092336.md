## 4. 风险点、影响范围、回滚方式

## 4.1 风险点

1. 推理执行器已切到统一注册路由，若后续新增策略未实现 `supports`，会在运行期抛 `unsupported_reasoning_strategy`。
2. ThoughtTree 参数映射由执行器转入统一输入，配置键变更需同步文档与调用方。
3. `ReasoningResult.details` 为通用 `Map`，新增字段需保持键名稳定。

## 4.2 影响范围

1. 受影响执行路径：`COT/DEBATE/THOUGHT_TREE` 三类步骤执行。
2. 受影响模块：`reasoning` 与 `runtime.step.executor`。
3. 外部 API 契约未变（仍输出原有字段），内部调用链改为注册表。

## 4.3 回滚方式

1. 代码级回滚：回退以下文件集至改造前版本：
   - `reasoning/common` 新增文件
   - `runtime/step/executor/ReasoningInputResolver.java`
   - 三个 `*StepExecutor` 与三类推理服务中的策略接口适配改动
2. 运行级回滚：以最近稳定构建包回滚部署。
3. 验证回滚：执行 `mvn test` + 关键链路冒烟（COT/DEBATE/THOUGHT_TREE）。
