# 新工程-P3改造任务清单（包设计合理性）-202602132330

**依据文档**
`doc/20260213/新工程-语义摘要替换-变更评估-202602132202.md`

**目标**
在`P3`阶段完成语义摘要的场景化与长度预算控制，并建立摘要与结构化结果的引用关系追踪机制，提升摘要可控性与可审计性，同时不破坏`meta/result/decision/summary`主协议。

**包设计合理性原则**
1. 摘要策略与预算控制必须位于`runtime.summary`子包，避免侵入执行层与反思层。
2. 引用关系追踪与映射应在`runtime.summary`或`runtime.output`内部完成，不依赖原始输出载体。
3. 场景配置与预算参数统一走`ConfigurationProperties`，严禁硬编码。
4. 输出协议字段变更必须由`RuntimeOutputKeys`集中管理，保持键一致性。
5. 记忆写入只消费语义摘要与引用，不回写原始输出内容。

---

## `P3`具体改造任务清单

1. **语义摘要场景化策略**
   目标：不同输出场景使用不同摘要策略，保证摘要粒度与用途一致。
   涉及包：`com.example.agent.runtime.summary`
   任务：
   - 新增`SemanticSummaryScenario`与`SemanticSummaryPolicyResolver`，根据`stepType/result.kind/decision`解析场景。
   - 新增`SemanticSummaryScenarioProperties`，支持按场景配置`maxChars/maxHighlights/maxOpenQuestions`等参数。
   - 在`SemanticSummaryService`中接入场景解析，生成摘要时按场景策略执行。

2. **摘要长度预算与裁剪控制**
   目标：对摘要长度进行预算管理，防止摘要膨胀影响上下文窗口。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.budget`
   任务：
   - 新增`SemanticSummaryBudgetResolver`，按`token/char`预算返回摘要长度上限。
   - 对摘要文本进行裁剪与规范化，保留关键句并保证可读性。
   - 引入摘要预算降级策略，预算不足时优先保留`highlights`与`openQuestions`。

3. **摘要与结构化结果引用关系追踪**
   目标：摘要可以追溯到结构化结果字段与证据来源。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.runtime.output`
   任务：
   - 新增`SummarySourceRef`模型，支持`resultPath/rawRef/toolRef`等引用类型。
   - 在摘要生成时构建`summary.sourceRefs`，仅保存引用，不携带原始数据。
   - 在`MemoryWriteSerializer`中序列化`summary.sourceRefs`，确保记忆可回溯。

4. **协议字段收敛与输出一致性**
   目标：保证`summary`扩展字段在协议层统一可控。
   涉及包：`com.example.agent.runtime.contract`、`com.example.agent.runtime.output`
   任务：
   - 在`RuntimeOutputKeys`中补充`summary.sourceRefs`与相关字段常量。
   - 在`FinalOutputService`中确认对外输出字段一致性，禁止输出未注册字段。

5. **测试与样例补齐**
   目标：覆盖场景策略、预算控制与引用追踪的核心路径。
   涉及包：`src/test/java/com/example/agent`
   任务：
   - 新增场景策略解析单测，验证不同`stepType`走不同策略。
   - 新增摘要预算裁剪单测，覆盖超限与降级分支。
   - 新增引用追踪单测，验证`summary.sourceRefs`序列化一致性。

## 验收标准
1. 摘要可根据场景生成，且策略与预算均可配置。
2. 摘要长度预算生效，超限时按降级规则裁剪。
3. `summary.sourceRefs`可追溯到结构化结果字段或证据引用。
4. 记忆写入仅携带摘要与引用，不携带原始输出。

## 测试建议
1. 执行全量测试：`mvn test`。
2. 增加预算为 0 与超大摘要的边界用例。
3. 覆盖`summary.sourceRefs`为空与多引用的组合场景。

## 风险与回滚
1. 场景策略配置不合理可能导致摘要过短或过长。
2. 引用追踪不完整可能影响审计与回放。
3. 回滚策略：关闭场景化配置与预算控制，使用默认摘要策略。
