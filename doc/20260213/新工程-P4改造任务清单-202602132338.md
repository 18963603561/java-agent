# 新工程-P4改造任务清单（包设计合理性）-202602132338

**依据文档**
`doc/20260213/新工程-语义摘要替换-变更评估-202602132202.md`

**目标**
在`P4`阶段完成语义摘要与结构化结果的可观测与运维能力建设，覆盖摘要生成耗时、命中率、失败率监控，以及结构化结果校验失败率与降级统计，形成可追踪、可报警、可回放的运行视图。

**包设计合理性原则**
1. 观测能力下沉到`runtime.summary`与`runtime.structured`子包内，避免跨层依赖执行层。
2. 指标输出统一使用现有指标发布器，禁止在业务层硬编码监控逻辑。
3. 日志字段与指标标签必须与`meta/result/decision/summary`协议对齐。
4. 观测开关与采样策略统一走`ConfigurationProperties`，禁止硬编码阈值。
5. 观测结果只承载统计信息，不携带原始输出内容。

---

## `P4`具体改造任务清单

1. **语义摘要生成链路指标**
   目标：覆盖摘要生成耗时、是否截断、摘要场景分布与失败率。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.streaming.observability`
   任务：新增`SemanticSummaryMetricsPublisher`或`SemanticSummaryObserver`，在`SemanticSummaryService`或`StepOutputSummaryBuilder`中记录`summary.generate.duration/summary.truncated/summary.scenario/summary.empty`等指标，并带上`stepType/toolName/scenario`标签。

2. **语义摘要质量与抽检统计指标**
   目标：统计质量评分分布、低质量触发次数与抽检命中率。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.runtime.summary.audit`
   任务：在`SemanticSummaryQualityScorer`和`SemanticSummarySampler`中发布质量评分区间、低分告警次数与抽检命中率指标，输出只包含评分与计数，不包含原始文本。

3. **结构化结果校验失败与降级指标**
   目标：统计结构化结果校验失败率、缺失字段数量与降级次数。
   涉及包：`com.example.agent.runtime.structured`
   任务：在`StructuredResultValidator`与`StructuredExtractorRegistry`中发布`structured.validation.failed/structured.missing_fields/structured.degrade`等指标，标签包含`kind/schemaVersion`。

4. **运行期摘要与结构化链路关键日志**
   目标：补齐摘要生成与结构化校验的关键日志，支持排障追踪。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.runtime.structured`
   任务：新增摘要生成开始/完成日志、结构化校验失败日志，日志包含`workflowId/stepId/stepType/rawRef/summaryScenario`，并保持日志级别约束（info/warn/error）。

5. **观测配置与指标命名规范**
   目标：统一指标命名、标签规范与开关策略。
   涉及包：`com.example.agent.runtime.summary`、`com.example.agent.runtime.structured`
   任务：新增`SemanticSummaryObserveProperties`与`StructuredObserveProperties`，提供`enable/sampleRate`等开关；统一指标前缀（如`agent.summary.*`与`agent.structured.*`），并在文档中列出指标字典。

## 验收标准
1. 摘要生成耗时、截断率与空摘要率可通过指标观测。
2. 摘要质量评分分布与抽检命中率可通过指标观测。
3. 结构化结果校验失败率与降级次数可通过指标观测。
4. 关键日志包含定位字段且无原始输出泄露。

## 测试建议
1. 执行全量测试：`mvn test`。
2. 增加摘要空文本与强制截断的观测用例。
3. 增加结构化校验失败与降级路径的观测用例。

## 风险与回滚
1. 指标维度过多可能导致监控成本上升，需要控制标签基数。
2. 日志过量可能影响性能，需要限制日志级别与采样。
3. 回滚策略：关闭观测开关，保留主流程不受影响。
