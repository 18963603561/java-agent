## 2. 本次代码改造范围

### 2.1 编排与降级治理

- `src/main/java/com/example/agent/reasoning/common/orchestrator/ReasoningOrchestrator.java`
  - 增加顺序降级执行链路：主策略失败时自动切换到下一个策略。
  - 增加并行执行计划日志、仲裁结果日志、降级命中日志。
  - 增加候选策略归一化与去重，避免重复执行。
  - 增加默认超时解析逻辑，支持配置驱动。
  - 并行无结果时不再只回退主策略，改为走统一降级链路。

- `src/main/java/com/example/agent/runtime/step/executor/ChainOfThoughtStepExecutor.java`
- `src/main/java/com/example/agent/runtime/step/executor/DebateStepExecutor.java`
- `src/main/java/com/example/agent/runtime/step/executor/ThoughtTreeStepExecutor.java`
  - 统一策略决策入口为：`preferredStrategy -> selector -> executionPlan`。
  - 统一并行开关与候选策略组装，减少执行器分散逻辑。

### 2.2 配置中心治理

- `src/main/java/com/example/agent/reasoning/common/config/ReasoningExecutionProperties.java`
  - 新增 `orchestrator` 配置域：`executorPoolSize`、`parallelTimeoutMillis`。

- `src/main/java/com/example/agent/reasoning/common/config/ReasoningConfigValidator.java`
  - 新增线程池大小校验与截断规则。
  - 新增并行超时校验与截断规则。

- `src/main/java/com/example/agent/reasoning/common/config/ReasoningConfigResolver.java`
  - 新增 `resolveExecutorPoolSize()`。
  - 新增 `resolveParallelTimeoutMillis()`。

- `src/main/java/com/example/agent/reasoning/common/orchestrator/ReasoningExecutionConfiguration.java`
  - 线程池大小改为读取配置解析器，不再硬编码常量。

### 2.3 强类型契约收敛

- `src/main/java/com/example/agent/reasoning/common/ReasoningResult.java`
  - 删除 `getDetails()` 动态映射兼容入口。
  - 强制上层通过 `ReasoningPayload` 读取结构化字段。

## 5. 风险评估

1. 由于删除了 `ReasoningResult.getDetails()`，外部若存在未纳入编译链的旧调用会在接入时暴露问题。
2. 顺序降级引入了额外策略尝试，极端失败场景下链路耗时会增加。
3. 并行执行线程池改为配置驱动，若配置过小会影响吞吐，过大可能放大资源竞争。
