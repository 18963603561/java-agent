# planning 解析链路微基准与分配分析报告

## 1. 文档目标

- 建立 `planning` 解析链路可复现的轻量性能基线。
- 输出一轮对象分配热点分析与等价优化结论。
- 保证优化仅增强工程质量，不改变业务行为。

## 2. 执行范围

- 代码范围：`src/main/java/com/example/agent/planning/parser/**`
- 测试范围：`src/test/java/com/example/agent/planning/parser/**`
- 不接入运行时主链路，仅在测试链路执行。

## 3. 微基准方案

### 3.1 基准入口

- 测试类：`PlanParserMicroBenchmarkTest`
- 用例：构造 60 步 TOOL 规划 JSON，执行 200 轮预热 + 2000 轮测量。
- 指标：单轮 `parseAttempt` 平均耗时（毫秒）。

### 3.2 可复现命令

`mvn -q "-Dtest=PlanParserMicroBenchmarkTest" test`

## 4. 分配热点分析

### 4.1 关注点

- `parseInternal` 在每个步骤循环内创建 `HashMap` 与 `ArrayList`。
- `steps` 列表默认容量较小，可能触发多次扩容。

### 4.2 本轮等价优化

1. `steps` 预分配容量：`new ArrayList<>(stepList.size())`。
2. `input` 容量按输入规模预估初始化：`new HashMap<>(Math.max(4, inputMap.size() + 4))`。
3. 无 `input` 时使用最小容量 `new HashMap<>(4)`，避免默认扩容路径。

### 4.3 行为一致性说明

- 仅调整集合初始化策略，不改变任何字段写入、校验与错误类型逻辑。
- 对外结果结构、错误码与回退行为保持一致。

## 5. 验证结果

- 回归测试：`mvn -q test` 通过。
- 微基准守卫：`PlanParserMicroBenchmarkTest` 断言 `avgMs > 0 && avgMs < 100`。
- 结论：本轮优化达到“低风险、可复现、可持续观察”的目标。

## 6. 后续建议

- 若进入专项性能周期，可再引入更细粒度剖析（如分场景样本拆分）。
- 继续坚持“基线先行、等价优化、全量回归”模式推进 P4 性能项。
