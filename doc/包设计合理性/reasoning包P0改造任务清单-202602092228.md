# reasoning 包 P0 改造任务清单

## 1. 目标与范围

基于 `doc/reasoning包设计与坏味道评估-202602092219.md` 的评估结论，P0 只处理“会直接影响结果正确性或稳定性”的问题。

本轮 P0 聚焦两个高风险点：

1. `DebateCoordinator` 提示词/注释/日志乱码，影响模型输出稳定性。
2. `ThoughtTreeService` 最优路径算法实现存在正确性风险（静态推断），可能导致 `bestPath` 与 `bestSolution` 失真。

## 3. 具体改造任务

### P0-RSN-01 Debate 文本乱码修复与模板治理

**目标**

- 消除 `DebateCoordinator` 中可见乱码，保证提示词语义可读且可控。

**改造范围**

- `src/main/java/com/example/agent/reasoning/debate/DebateCoordinator.java`
- （可选）`src/test/java/com/example/agent/reasoning/DebateCoordinatorTest.java`

**具体工作项**

1. 修复类注释、方法注释、日志文案中的乱码中文。
2. 重写 `buildPrompt(String topic)` 中的中文提示词，确保约束完整。
3. 明确提示词中的输出格式约束，仅允许单个 JSON 对象。
4. 为提示词增加最小样例与字段说明，降低模型偏航概率。

**交付物**

- 可读、无乱码的 `DebateCoordinator` 源码。
- 至少 1 条断言覆盖提示词关键约束（推荐新增单测或扩展现有单测）。

**验收标准**

- `DebateCoordinator.java` 全文件无乱码文本。
- 单测通过，且日志中不再出现乱码中文。

---

### P0-RSN-02 Debate 输出收敛与防噪声保护

**目标**

- 避免 `parseConclusion` 解析失败时直接透传原始噪声文本。

**改造范围**

- `src/main/java/com/example/agent/reasoning/debate/DebateCoordinator.java`
- `src/test/java/com/example/agent/reasoning/DebateCoordinatorTest.java`

**具体工作项**

1. 新增结论清洗函数（如 `sanitizeConclusion`）。
2. 对解析失败路径增加长度截断和空值保护策略。
3. 对“无有效结论”场景输出稳定占位值（避免原始杂讯泄露）。
4. 在异常分支补充 `warn` 级日志与上下文字段（topic/workflowId）。

**交付物**

- Debate 输出在异常场景仍保持结构化与可控长度。
- 新增 2~3 条单测覆盖：空响应、噪声响应、修复失败路径。

**验收标准**

- `round.getConclusion()` 不再返回明显噪声串。
- 所有 Debate 相关测试通过。

---

### P0-RSN-03 ThoughtTree 最优路径算法重构

**目标**

- 修复 `findBestPath` 潜在路径失真问题，保证 `bestPath` 是真实根到叶路径。

**改造范围**

- `src/main/java/com/example/agent/reasoning/thoughttree/ThoughtTreeService.java`

**具体工作项**

1. 替换当前“共享 `path` 栈 + `push/pop`”实现。
2. 改为以下任一稳定方案：
   - 递归 DFS（参数携带当前路径副本）；
   - 显式栈结构（元素包含 `node + pathSnapshot`）。
3. 保证叶子评分比较时，使用的是该叶子的真实完整路径。
4. 对回溯分支（`backtrackEnabled`）保持兼容，不改变外部契约。

**交付物**

- 新版路径搜索实现。
- `bestSolution` 与 `bestPath` 结果一致性提高（由测试证明）。

**验收标准**

- 任意返回路径都满足父子链路可追溯。
- 关键路径单测通过（见 P0-RSN-04）。

---

### P0-RSN-04 ThoughtTree 正确性测试补齐

**目标**

- 用可重复的单元测试锁定路径算法正确性，防止回归。

**改造范围**

- `src/test/java/com/example/agent/reasoning/ThoughtTreeServiceTest.java`

**具体工作项**

1. 新增“路径完整性”测试：`bestPath` 中每个节点的 `parentId` 与前一节点 `nodeId` 一致。
2. 新增“根节点起始”测试：`bestPath` 第一节点必须是 `root`。
3. 新增“解答一致性”测试：`bestSolution` 中步骤顺序与 `bestPath` 顺序一致。
4. 新增“终止节点选择合理性”测试：存在终止节点时优先路径可命中高分叶子。

**交付物**

- ThoughtTree 新增 3~4 条单测。

**验收标准**

- ThoughtTree 测试全通过。
- 新增测试在旧实现上可复现失败（建议本地确认一次）。

---

### P0-RSN-05 P0 回归验证与上线门禁

**目标**

- 确保 P0 改造后不引入已有能力回退。

**执行清单**

1. 运行定向测试：

```bash
mvn "-Dtest=ChainOfThoughtServiceTest,DebateCoordinatorTest,ThoughtTreeServiceTest" test
```

2. 运行与推理执行器耦合相关测试（若存在）并记录结果。
3. 人工抽样验证日志可读性（重点看 Debate 与 ThoughtTree 关键日志）。
4. 在变更说明中记录：风险点、回滚方式、影响范围。

**门禁标准（全部满足才可合并）**

- 相关单测全部通过。
- `reasoning` 包新增/修改代码无乱码文本。
- `DebateCoordinator` 输出契约稳定（结论字段可控、非噪声透传）。
- `ThoughtTreeService` 路径正确性测试通过。
