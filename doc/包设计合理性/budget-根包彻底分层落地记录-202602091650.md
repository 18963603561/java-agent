# budget 根包彻底分层落地记录

## 1. 实施目标

- 依据 `doc/budget-根包分层彻底性分析-202602091530.md`，继续推进 `com.example.agent.budget` 根包彻底分层。
- 目标是让 `budget` 子域从“类级解耦”升级为“包级分层解耦”，并通过守卫测试防止结构回退。
- 该轮改造严格按新方案直接落地，不保留历史兼容分支。

## 2. 分阶段实施结果

### 2.1 阶段 A：配置语义迁出 `core`

- 将 `ContextBudgetProperties` 从 `budget/core` 迁移到 `budget/config`。
- 主工程与测试工程中所有引用全部切换到新路径。
- 结果：`core` 保持纯领域模型职责，不再承载 Spring 配置装配语义。

- 新增并落地 `token/application`、`token/model`、`token/repository`、`token/event`、`token/pricing`。
- 将模型对象迁移到 `token/model`：
  - `TokenUsageInput`
  - `TokenUsageRecord`
  - `TokenUsageSummary`
- 将应用编排与服务接口/实现迁移到 `token/application`：
  - `TokenBudgetManager`
  - `ContextBudgetAllocator` / `DefaultContextBudgetAllocator`
  - `BudgetThresholdEvaluator` / `DefaultBudgetThresholdEvaluator`
  - `TokenUsageRecordFactory` / `DefaultTokenUsageRecordFactory`
  - `TokenUsageRecorder` / `DefaultTokenUsageRecorder`
  - `TokenUsageSummaryService` / `DefaultTokenUsageSummaryService`
  - `ContextBudgetRequest`
- 将仓储接口与实现迁移到 `token/repository`：
  - `TokenUsageRepository`
  - `InMemoryTokenUsageRepository`
  - `JdbcTokenUsageRepository`
- 将事件发布接口与实现迁移到 `token/event`：
  - `BudgetEventPublisher`

- 保留并确认 `CostCalculator` 在 `token/pricing`。
- 补充仓储关键路径日志（内存仓储）与异常上下文日志（数据库仓储已有）。

### 2.3 阶段 C：`trim` 包按层次拆分
