# rawRef 调试说明-202602140447

## 1. 设计原则
1. 原始输出不进入主流程，仅保留 `rawRef` 引用。
2. 生产默认关闭原始数据展示，避免泄露。
3. 调试路径必须脱敏与权限控制。

## 2. 调试取回流程
1. 主流程仅保存 `rawRef`，不保存原文。
2. 需要排查时通过调试接口按 `rawRef` 取回。
3. 调试接口应支持限权、审计与脱敏。

## 3. 推荐策略
1. 生产环境默认关闭 raw 输出。
2. 灰度或调试环境可开启 raw 输出。
3. 对含敏感信息的数据强制脱敏。

## 4. 调试接口模板示例
```text
GET /internal/raw/{rawRef}
- 权限：仅管理员/灰度账号
- 审计：记录调用人、时间、rawRef
- 脱敏：按配置策略处理
```
