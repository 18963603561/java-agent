# 返回结果结构改造任务清单

## P0 必做
1. 增加原始快照输出开关文档与配置示例
- 目标：明确如何开启 `agent.summary.rawEnable=true` 输出原始快照。
- 验收：配置开启后 `steps[*].raw` 不再为 `null`。

2. 前端展示层引入连续步骤编号
- 目标：在展示层基于 `steps` 列表生成 `stepIndex`，不复用 `seq`。
- 验收：前端展示连续编号，`seq` 保持原义。

## P1 重要优化
3. 摘要预算策略调整
- 目标：当 `maxChars=0` 时默认“全文输出不截取”，避免摘要文本被抑制。
- 验收：配置 `maxChars=0` 后 `summary.text` 不为空且不被截断。

4. 步骤级摘要策略开关
- 目标：对外统一 `SummaryRequestOverrides` 或场景策略开关，默认关闭模型/模板摘要。
- 验收：默认不走模型/模板，按场景开启后才执行。

## P2 体验优化
5. 响应精简模式
- 目标：新增 `responseMode=compact/full`，默认精简。
- 精简规则：移除 `null` 字段与空数组；重复的 `planSummary`、`answer/summary` 去重。
- 验收：`compact` 返回体明显缩小且不影响核心数据。

6. 摘要一致性处理
- 目标：当 `finalOutput.result.answer` 与 `finalOutput.summary.text` 相同，保留其一。
- 验收：重复内容消除，语义不变。

## P3 可选优化
7. 步骤摘要裁剪策略
- 目标：摘要关闭或无 `text` 时仅保留 `highlights`。
- 验收：`summary` 字段不再冗余。

8. 质量字段一致性
- 目标：`quality.truncated` 统一布尔值（如 `false`）。
- 验收：质量结构字段类型一致。

## 风险与依赖
- 原始快照输出需关注脱敏与权限控制。
- 精简模式需确保下游兼容现有字段。

## 测试建议
- 配置切换测试：`rawEnable`、`responseMode`、摘要策略开关。
- 回归测试：工具步骤、LLM 步骤、异常步骤三类场景。
