## 一、P5 具体改造任务清单

### 1. 对外输出协议文档与示例（体验优先）
**目标**：补齐 `meta/result/decision/summary` 协议说明、字段约束、示例与变更说明。
- **任务**
  1. 在 `doc/20260214/` 新增协议说明文档，包含字段说明、可选字段、边界与回退逻辑。
  2. 增加 3 组示例：
     - 正常工具执行
     - 结构化校验失败降级
     - 摘要关闭（仅 result + summary 为空）
  3. 标注“原始输出仅调试可见”的说明与 rawRef 取回流程。
- **包设计合理性**
  - 文档落盘，不在业务代码内硬编码文本模板。
  - 示例数据与真实结构严格对齐 `runtime.contract.RuntimeOutputKeys`。
- **涉及文件**
  - `doc/20260214/输出协议说明-202602140417.md`

### 2. 请求级配置覆盖（策略可控）
**目标**：允许在请求维度覆盖摘要与结构化策略，保持默认全局配置。
- **任务**
  1. 在 `runtime.summary` 增加“请求级覆盖模型”，例如 `SummaryRequestOverrides`。
  2. 在摘要入口解析覆盖参数：
     - 是否启用摘要
     - 场景策略选择
     - 最大长度/列表上限
  3. 保持默认配置不受影响，覆盖参数只影响当前请求。
- **包设计合理性**
  - 覆盖模型放在 `runtime.summary`，避免 `api` 直接依赖内部策略类。
  - 入参转换层在 `api` 或 `runtime.engine` 统一映射，避免散落。
- **涉及文件**
  - `src/main/java/com/example/agent/runtime/summary/*`
  - `src/main/java/com/example/agent/runtime/engine/*`

### 3. 语义摘要场景配置治理（体验一致）
**目标**：对场景化摘要策略提供可配置说明与默认值，并输出可读日志。
- **任务**
  1. 在 `SemanticSummaryScenarioProperties` 增加“场景枚举 + 说明文档”。
  2. 提供“默认场景 fallback”与“空场景处理”说明。
  3. 在摘要日志里输出“场景命中来源”（默认/覆盖/推断）。
- **包设计合理性**
  - 场景策略只依赖 `runtime.summary` 子包，避免引入业务域模型。
- **涉及文件**
  - `src/main/java/com/example/agent/runtime/summary/*`
  - `doc/20260214/语义摘要场景说明-202602140417.md`

### 4. 结构化结果与摘要开关说明（可运营）
**目标**：为运维/使用方提供配置说明，避免误开误关影响主流程。
- **任务**
  1. 输出配置说明文档：
     - `agent.summary.*`
     - `agent.summary.observe.*`
     - `agent.structured.observe.*`
  2. 给出默认值、影响范围与回滚策略。
  3. 明确：`summary` 开关只影响“额外上下文”，不影响 `result` 主路径。
- **包设计合理性**
  - 配置说明放在 `doc`，避免写死到代码注释。
- **涉及文件**
  - `doc/20260214/配置说明-202602140417.md`

### 5. 原始数据调试可见路径（体验闭环）
**目标**：对外解释 rawRef 的用途，提供“调试取回流程”。
- **任务**

     - 灰度/调试可启用
     - 脱敏与权限控制
  2. 提供“调试接口返回示例”文档模板。
- **包设计合理性**
  - 调试路径不进入主流程包，仅通过 API 或运维接口暴露。
- **涉及文件**
  - `doc/20260214/rawRef调试说明-202602140417.md`

### 6. 用户体验样例与常见问题（体验补全）
**目标**：降低接入成本，统一使用方式与预期。

- **涉及文件**
  - `doc/20260214/接入指南与FAQ-202602140417.md`

## 二、验收标准
1. 对外协议文档与示例完整，可直接复制作为 API 使用说明。
2. 请求级覆盖可控制摘要策略，但不影响 `result` 主路径。
3. 配置项默认值、影响范围、回滚策略清晰可查。
4. rawRef 调试路径有明确说明与安全控制约束。
5. FAQ 覆盖主要使用疑问。

---

## 三、风险与回滚
1. 过多配置项可能导致误用：通过文档约束与默认值规避。
2. 请求级覆盖滥用可能引发不一致：限制可覆盖字段并记录日志。
3. rawRef 调试开关误开风险：必须权限控制并默认关闭。
