# 配置说明-202602140447

## 1. 摘要主配置（agent.summary.*）
1. `agent.summary.enable`：是否启用摘要。默认 `true`。
2. `agent.summary.maxChars`：摘要文本最大字符数。默认 `4000`。
3. `agent.summary.maxListItems`：摘要列表最大条目数。默认 `20`。
4. `agent.summary.maxFieldChars`：单字段最大字符数。默认 `1000`。
5. `agent.summary.strategy`：步骤摘要构建策略。可选 `semantic/template/model/off`，默认 `semantic`。
6. `agent.summary.rawEnable`：原始输出调试开关。默认 `false`。
7. `agent.summary.rawMaxChars`：原始输出最大字符数。默认 `4000`。
8. `agent.summary.rawMaxFieldChars`：原始输出单字段最大字符数。默认 `1000`。
9. `agent.summary.rawMaxListItems`：原始输出列表最大条目数。默认 `20`。

### 1.1 原始快照输出（rawEnable）
1. 作用：开启后 `steps[*].raw` 输出原始快照，`steps[*].rawRef` 仍可用于回溯原始数据。
2. 默认：`false`，建议仅在调试或灰度环境开启。
3. 限制：原始快照受 `rawMaxChars`、`rawMaxFieldChars`、`rawMaxListItems` 约束，超限会被截断并标记为截断。

示例配置：
```yaml
agent:
  summary:
    raw-enable: true
    raw-max-chars: 4000
    raw-max-field-chars: 1000
    raw-max-list-items: 20
```

### 1.2 摘要预算语义（maxChars）
1. 规则：`maxChars=0` 表示“不限制长度”，不会抑制 `summary.text`。
2. 截断：仅当 `maxChars>0` 且超长时才截断，并将 `truncated` 标记为 `true`。
3. 覆盖：请求级 `context.summary.maxChars` 与场景策略 `maxChars` 遵循同一规则。

### 1.3 策略优先级（strategy）
1. 优先级：请求级覆盖 `context.summary.strategy` > 场景策略 `agent.summary.scenario.policies.*.strategy` > 全局 `agent.summary.strategy`。
2. 默认：`semantic`，默认不走 `template/model`。
3. 关闭：`strategy=off` 时，步骤级 `summary` 返回空映射。

## 2. 摘要观测配置（agent.summary.observe.*）
1. `agent.summary.observe.enable`：摘要观测开关。默认 `true`。
2. `agent.summary.observe.sampleRate`：观测采样率。默认 `1.0`。
3. `agent.summary.observe.logSampleRate`：摘要日志采样率。默认 `1.0`。

## 3. 结构化观测配置（agent.structured.observe.*）
1. `agent.structured.observe.enable`：结构化观测开关。默认 `true`。
2. `agent.structured.observe.sampleRate`：观测采样率。默认 `1.0`。
3. `agent.structured.observe.logSampleRate`：结构化日志采样率。默认 `1.0`。

## 4. 请求级覆盖（仅作用当前请求）
1. `context.summary.enabled`：摘要开关覆盖。
2. `context.summary.scenario`：摘要场景覆盖。
3. `context.summary.maxChars`：摘要最大字符数覆盖。
4. `context.summary.maxListItems`：摘要列表最大条目数覆盖。
5. `context.structured.enabled`：结构化结果开关覆盖。

## 5. 约束与回退
1. 摘要开关仅影响“额外上下文”，不改变 `result` 主路径。
2. 覆盖参数缺失时使用全局默认配置。
3. 负数或非法值会被归零或忽略。
