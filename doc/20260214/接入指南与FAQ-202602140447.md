# 接入指南与FAQ-202602140447

## 1. 接入要点
1. 输出协议固定为 `meta/result/decision/summary`。
2. `result` 为主路径，`summary` 为增强项。
3. `rawRef` 仅用于调试取回，不参与主流程。

## 2. FAQ：为什么 summary 为空
1. 摘要开关关闭（全局或请求级覆盖）。
2. 场景预算将 `maxChars` 设为 0。
3. 上游输出缺少可摘要字段。

## 3. FAQ：summary 与 result 的区别
1. `result`：结构化主数据，用于主流程判断与回归。
2. `summary`：语义压缩文本，用于额外上下文与观测。

## 4. FAQ：结构化失败如何降级
1. 结构化校验失败时，`result` 进入错误类型并附带原因。
2. 主流程可继续读取 `summary` 或 `decision`。

## 5. FAQ：如何开启摘要与观测
1. 打开 `agent.summary.enable`。
2. 打开 `agent.summary.observe.enable`。
3. 需要时在请求里设置 `context.summary.*` 覆盖。
