# 语义摘要场景说明-202602140447

## 1. 场景来源
1. `override`：请求级覆盖指定场景。
2. `inferred`：基于结果/决策/步骤/工具推断。
3. `default`：未命中任何规则时使用默认场景。

## 2. 场景解析顺序
1. 请求级覆盖（`context.summary.scenario` 或 `summary.scenario`）。
2. `result.kind`（命中 `result:<kind>`）。
3. `decision` 字段（命中 `decision`）。
4. `stepType`（命中 `step:<stepType>`）。
5. `toolName`（命中 `tool`）。
6. 默认场景（`default`）。

## 3. 场景编码约定
1. `default`：默认场景。
2. `result:<kind>`：结构化结果场景。
3. `decision`：决策场景。
4. `step:<stepType>`：步骤场景。
5. `tool`：工具场景。

## 4. 场景配置说明
1. 配置前缀：`agent.summary.scenario`。
2. `defaultPolicy`：默认场景预算策略。
3. `policies.<scenarioCode>`：指定场景策略。
4. `policies.<scenarioCode>.description`：场景说明，可选。

## 5. 空场景与回退
1. 场景为空或未知时，自动回退到 `defaultPolicy`。
2. 未配置的场景不会导致异常，仅影响预算使用默认值。

## 6. 日志与观测
1. 摘要日志输出 `scenario` 与 `scenarioSource`。
2. `scenarioSource` 值域：`default` / `override` / `inferred`。
