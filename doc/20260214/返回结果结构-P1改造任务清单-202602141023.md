# 返回结果结构 P1 改造任务清单

## 目标与范围
1. 目标：完善步骤级摘要预算语义与摘要策略开关，使摘要输出稳定且可控。
2. 范围：仅 P1 任务，不改变 P0 已落地能力，不引入跨层耦合。

## P1 任务清单（按包职责拆分）

### 1. 摘要预算策略调整（maxChars=0 全文输出）
1. 所在包/模块
- 摘要生成：`com.example.agent.runtime.summary`（`SemanticSummaryService`）
- 预算解析：`com.example.agent.runtime.summary`（`SemanticSummaryBudgetResolver`）
- 配置：`com.example.agent.runtime.summary`（`StepSummaryProperties`）
- 文档：`doc/20260214/配置说明-202602140447.md`
2. 任务内容
- 统一规则：`maxChars=0` 表示“不限制长度”，仅 `maxChars>0` 才执行截断。
- 兼容覆盖：请求级覆盖与场景策略若传入 `0`，按“不限制长度”处理，不清空 `summary.text`。
- 质量标记：未截断场景 `truncated=false`，避免误报。
3. 验收标准
- 配置 `maxChars=0` 时，`summary.text` 仍输出完整文本且不被截断。
- 配置 `maxChars>0` 时，超长文本按预算截断并标记 `truncated=true`。
- 请求级覆盖 `maxChars=0` 与场景策略一致生效。

### 2. 步骤级摘要策略开关（默认关闭模型/模板）
1. 所在包/模块
- 摘要策略入口：`com.example.agent.runtime.summary`（`StepOutputSummaryBuilder`）
- 策略定义：`com.example.agent.runtime.summary`（新增枚举/策略选择器）
- 场景配置：`com.example.agent.runtime.summary`（`SemanticSummaryScenarioProperties`）
- 请求级覆盖：`com.example.agent.runtime.summary`（`SummaryRequestOverrides`）
- 文档：`doc/20260214/配置说明-202602140447.md`
2. 任务内容
- 新增策略字段（示例：`semantic`/`template`/`model`/`off`），默认 `semantic`，显式关闭 `template` 与 `model`。
- `SummaryRequestOverrides` 增加 `strategy` 解析，支持请求级覆盖。
- `SemanticSummaryScenarioProperties` 增加 `strategy` 字段，支持场景化策略。
- `StepOutputSummaryBuilder` 按策略路由摘要生成器，未开启时不走模型/模板。
- 模型/模板摘要失败时回退 `semantic`，保持稳定输出。
3. 验收标准
- 默认配置下不调用模型/模板摘要，仅输出语义摘要。
- 开启场景或请求级策略后，按策略执行，并可回退至语义摘要。

## 包设计合理性检查要点（P1 约束）
1. 策略与生成解耦：策略选择独立于摘要生成实现，便于扩展。
2. 覆盖入口统一：场景策略与请求级覆盖通过同一解析入口生效。
3. 不跨层写入：配置与文档仅在 `doc` 与 `runtime.summary` 内闭环。
